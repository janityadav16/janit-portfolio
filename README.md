## 📦 SETUP & LOCAL INSTALLATION

Because the entire ecosystem is built with vanilla web technologies, there are zero heavy frameworks to compile or configure!

### 1. Clone the Arsenal
```bash
git clone https://github.com/janityadav16/janit-portfolio-main.git
cd janit-portfolio-main
```

### 2. Run Locally
You can open `index.html` directly in any web browser, or launch a lightweight static dev server:

**Using Node.js (`http-server`):**
```bash
npx http-server . -p 3000
```

**Using Python:**
```bash
python3 -m http.server 3000
```
