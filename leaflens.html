ABOUT THE PROJECT

LeafLens is an AI-powered application that uses Convolutional Neural Networks to detect diseases in plant leaves. Built to help farmers and gardeners identify crop issues instantly without needing expert consultation.

TECH STACK
PythonDeep LearningCNNOpenCVFlaskResNet50
KEY FEATURES
  • Real-time Disease Detection
  • High Accuracy CNN Model (99.1%)
  • Supports Multiple Plant Species
  • Flask Web Interface
HOW IT WORKS
01. Upload leaf image
02. CNN model analyzes patterns
03. Disease identified with confidence score
LESSON // Learned ResNet50 fine-tuning, transfer learning strategies, and Flask deployment pipelines for production-grade ML applications.
